# AI-UI-UX-Review-Agent

## Overview

AI-UI-UX-Review-Agent is an AI-powered system that analyzes application screenshots to detect UI/UX issues and generate professional UX review reports.

## Project Goal

- Upload application screenshots
- Detect UI/UX issues using AI
- Generate actionable recommendations
- Produce professional reports
